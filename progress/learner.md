- 补充（2026-09-25 晚七）：**`test` / `[` 是当晚最大的一个坑**，他的四次尝试全错在不同地方，说明这个概念的
  心智模型是空白的——他以为 `test` 是个**会回显答案**的东西。原话"这个 test 到底咋用"。
  正确讲法（已验证）：`test` 是**只举手不说话的裁判**——结果在**退出码**里，一个字符都不打印。
  三层配套误解要一次各拆一个：① `echo test ...` = 只是在**念**纸条，没执行 test；
  ② `$( )` = 取"命令说出来的一句话"，裁判不说话 → 空串；③ 结果要看 `; echo $?` 或 `if`。
  两个必须点出来的语义坑（实测）：`[ -f ]`（单参数）= "`-f` 这个字符串非空吗" → **exit 0（真）**，是极难发现的静默 bug；
  退出码 **2 = 语法错**（不是假），`if` 会**静默走 else 分支**。
  写法铁律：`[` 前后**必须有空格**（`["world"` 会粘成一个词 `[world`）；`test [ ... ]` 混写 → `too many arguments`。
  `[` 就是 `test`，只是要求最后一个参数是 `]`。出题时这是现成的第 3–4 级考点。
