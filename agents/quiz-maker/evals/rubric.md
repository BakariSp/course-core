# 单元题的评分标准

每项 1–5 分。5 = 可以直接给学习者做；3 = 能用但有明显缺陷；1 = 会误导学习者。

- `aligned` 对得上目标：每道题检验的是这个单元 outcomes 里的一件事；新学的核心概念都有题，没有考课程里没教的东西。
- `targeted` 针对这个学习者：表现里的薄弱点（错过的检查点、高级提示、没看懂的词）有换了场景的变体，不是原题重出。
- `unambiguous` 没有歧义：题干、答案、解析说的是同一件事；按题干字面意思答对的人一定被判对；选择题只有一个说得通的答案（多选题写明多选）。
- `levels` 难度有梯度：从 1 级到 4 级都有，4 级题真的是找 bug / 判断取舍，不是换个说法的记忆题。
- `checkable` 判分可靠：代码题的测试测的是行为和边界，而不是某种写法；终端题的检查项检验结果，而不是用了哪条命令；简答题的 rubric 每条都能对着答案判断。
