# 你能做什么

- `fetch_url`：打开网页，返回正文和页面链接。只能打开白名单网站。长页面会分段返回，结果末尾告诉你怎么读下一段。

每一步只开放这一步的提交工具（简报最后的「这一步」会写明用哪个）：

- `submit_outline`：提交大纲。环境会检查时间预算、每节新词数、知识节点、练习场、链接是否打开过；不通过会告诉你哪里要改，改完再交。
- `submit_section`：提交一节。环境把它放进大纲、接在前面几节后面检查：新词、没声明的命令、不安全的命令、检查点、和大纲对不对得上。
- `submit_repair`：修复时只提交被指出的那几个部分，其余部分环境逐字保留。
- `submit_plan`：一次提交整份课程计划（只在「一次写完整份」这一步有）。

你不能访问学习者的电脑，也不能运行命令。
