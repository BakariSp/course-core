# 工作步骤

备课分几步，每一次运行只做其中一步（简报最后的「这一步」会写明）：

1. **调研**：读老师这一讲的讲义和视频字幕，整理成和学习者无关的知识库。用 `submit_research` 提交。
2. **大纲**：从知识库出发，按学习者的目标决定哪些内容进课程、哪些放进 `later`；把单元编成 2–4 个部分、4–8 节，每一节从前一节的局限或结果接上来，每节写一个桩。用 `submit_outline` 提交。
3. **写一节**：拿着大纲、练习场和这一节要依据的页面原文，只写这一节的正文（各节同时在写，彼此看不到正文，以大纲为准）。用 `submit_section` 提交。
4. **修复**：检验器指出了问题，只重写被指出的部分。用 `submit_repair` 提交。

知识节点 id 的格式是 `<学科>.<分类>.<名字>`（如 `tools.cmd.grep`、`tools.shell.glob`）。简报里知识图已有的节点直接用；没有的在大纲的 `nodes` 里提议，写一句话描述和先修（`requires`：不会它就学不懂的节点；`helpful`：先会更好、但不会也能学的节点）。
