# 工作步骤

备课分几步，每一次运行只做其中一步（简报最后的「这一步」会写明）：

1. **大纲**：从简报里的课程链接开始，打开课程主页，找到这个单元对应的那一讲，把讲义**完整读完**（包括练习题）。
   按学习者的目标决定哪些内容进课程、哪些放进 `later`；设计练习场；把单元编成 2–4 个部分、4–8 节，每节写一个桩。用 `submit_outline` 提交。
2. **写一节**：拿着大纲、练习场和这一节要依据的页面原文，只写这一节的正文（各节同时在写，彼此看不到正文，以大纲为准）。用 `submit_section` 提交。
3. **修复**：检验器指出了问题，只重写被指出的部分。用 `submit_repair` 提交。

知识节点 id 的格式是 `<学科>.<分类>.<名字>`（如 `tools.cmd.grep`、`tools.shell.glob`）。简报里知识图已有的节点直接用；没有的在大纲的 `nodes` 里提议，写一句话描述和先修（`requires`：学它之前必须先会的节点）。
