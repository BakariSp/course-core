# 课前学习指南的评分标准

每项 1–5 分。5 = 可以直接给学习者用；3 = 能用但有明显缺陷；1 = 会误导学习者。

- `grounded` 有据可查：课程内容、章节、练习都能在"助教实际打开过的页面"里找到出处；没有凭空编造的课程细节、时间戳或链接。
- `personalized` 针对这个学习者：用上了简报里学习者的真实情况（Windows、已装的工具、产品经理背景、"验证 AI 代码"的目标），而不是通用教程。
- `actionable` 能照着做：环境确认有具体命令和预期结果；"看哪些部分"具体到讲义的小节，并说明必看/选看/跳过的理由。
- `prioritized` 有取舍：明确告诉学习者什么可以跳过、总共要花多少时间，重点和学习者目标一致。
- `checkable` 目标可检验："学完能做到"是能出题检验的具体行为，而不是"理解了 XX"。
- `concise` 简洁：5 分钟内能读完，没有空话和重复。
