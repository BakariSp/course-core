# 课程计划的评分标准

每项 1–5 分。5 = 可以直接给学习者用；3 = 能用但有明显缺陷；1 = 会误导学习者。

- `teaches` 是讲课不是指路：只读每一节的讲解就能学会这一节，不需要学习者自己再去翻讲义或视频（REF: F-013）。
- `grounded` 有据可查：概念、命令、练习都能在"助教实际打开过的页面"里找到出处；没有编造的课程细节、时间戳或链接。
- `novice_readable` 新手看得懂：术语第一次出现时有解释；每个坑都有学习者会亲眼看到的现象、原因和具体的解决命令（REF: F-013）。
- `personalized` 针对这个学习者：动手命令能在学习者实际的环境里跑通，预期结果按那个环境写；内容取舍服务于学习者的目标。
- `timeboxed` 取舍合理：各节分钟数真实（没有为了塞内容而压低）；放进 later 的内容确实次要，理由说得清（REF: F-014）。
- `checkable` 目标可检验：每节的 goal 和整体的 outcomes 都是能出题检验的具体行为。
